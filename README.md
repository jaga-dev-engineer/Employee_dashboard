# Employee Dashboard

The application code and local setup instructions are in [`employee_dashboard/`](./employee_dashboard/).

For a public **demo** deployment, this repository includes a Render Blueprint at [`render.yaml`](./render.yaml). It serves the synthetic sample workbook, not the private `Employee_data.xlsx`. The free service does not provide persistent storage for manager-edited workbooks; do not deploy real employee data this way. See [`employee_dashboard/SETUP.md`](./employee_dashboard/SETUP.md) for deployment steps and limitations.
